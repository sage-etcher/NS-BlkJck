# Northstar Advantage Blackjack

Graphical Blackjack Game written to run either as a bare-metal program for 
the NorthStar Advantage Computer, cerca 1981, or on said computer under 
CP/M (default configuration).

Runs a graphical game of Blackjack and utilizes no PROM or OS functions, 
everything in this program is self contained.

- Implements Hit, Stand, and Double.
- Betting, Splitting, and Late Surrender are not implemented.
- Uses Real Deck, Card Counting is possible.

The Assembly is written with intent to be Assembled using CP/M's
native intel 8080 assembler, `ASM.COM`.

All code is written in Intel 8080 Mnemonic Assembly.
